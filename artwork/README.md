# 应用图标与配色

`neta-music-icon.png` 是基于用户提供的哪吒听歌插画处理后的图标母版：保留笑脸、双发髻、耳机和朱红暖金配色，去掉预制圆角和白色角区，并扩大人物周围留白。

安装 ImageMagick 后，在仓库根目录运行：

```sh
./scripts/export-icons.sh
```

脚本导出 512px 的共用图像和 mdpi 至 xxxhdpi 的传统桌面图标。Android 8.0 及以上使用自适应图标，前景每侧按图层宽度留白 13%（108dp 图层约为 14dp），随桌面图标大小缩放；外层遮罩由桌面决定，关于页使用同一幅图像。

默认配色为“朱红暖金”。朱红种子色为 `#C93426`，辅助色为铜棕 `#9E6B3D` 和暖金 `#D49A30`，背景采用暖灰色阶。界面、深色播放页和小组件共用 `ui/theme/Palette.kt` 的 MaterialKolor 色板，保留深浅主题、对比度及用户自选配色功能。
